# 🚗 CarzSpas AI WhatsApp Booking & Customer Engagement Workflow

AI-powered customer engagement and booking automation workflow built using **n8n**, **OpenAI/Gemini**, **WhatsApp Business API**, and **PostgreSQL**.

This workflow automates customer conversations, appointment bookings, lead qualification, follow-ups, and service inquiries for CarzSpas car detailing and ceramic coating services.

# ⚙️ Setup Instructions

## 1️⃣ Import Workflow

- Open n8n
- Import the provided JSON workflow file

## 2️⃣ Configure Credentials

Setup:

- WhatsApp Business API
- OpenAI API
- Gemini API
- PostgreSQL
- Gmail (optional)

## 3️⃣ Configure Environment Variables

```env
OPENAI_API_KEY=
GEMINI_API_KEY=
WHATSAPP_ACCESS_TOKEN=
VERIFY_TOKEN=
DATABASE_URL=
```

## 4️⃣ Activate Workflow

- Enable webhook URLs
- Activate the workflow
- Test WhatsApp interactions
